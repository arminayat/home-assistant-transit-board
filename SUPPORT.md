# Support

Start with the [README](README.md), then [Installation](docs/installation.md), [Configuration](docs/configuration.md) and [Troubleshooting](docs/troubleshooting.md).

Transit Board is a beta Home Assistant app for Berlin and Brandenburg, accessed through Ingress. It needs Supervisor's Apps support and an amd64 or aarch64 system.

## Questions and problems

- Ask usage questions in a [GitHub issue](https://github.com/arminayat/home-assistant-transit-board/issues/new?title=Question%3A%20).
- Use the [bug report form](https://github.com/arminayat/home-assistant-transit-board/issues/new?template=bug_report.yml) for reproducible problems. Include the app, Home Assistant OS and Supervisor versions, architecture and sanitized logs when relevant.
- Use the [feature request form](https://github.com/arminayat/home-assistant-transit-board/issues/new?template=feature_request.yml) to explain a problem the app does not solve.
- Report vulnerabilities through the [private process](SECURITY.md).

Search existing issues first. Describe what you expected, what happened and how to reproduce it. Avoid uploading a full app backup or configuration file; a small fabricated or redacted example is usually sufficient. Review screenshots and logs for tokens, private hostnames and personal travel/location information before sharing.

Realtime information and availability depend on the public BVG REST service. A provider outage does not by itself establish an app defect. Mention the visible error and approximate time when relevant.

Support is public on GitHub as maintainer time permits. There is no private email support channel or guaranteed response time.
